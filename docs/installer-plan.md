# Plan: Native Installer Packages

**Created:** 2026-03-29
**Updated:** 2026-04-02

## Overview

Create native installers for AutoOrtho Rust across all three platforms:
- **Windows**: MSI installer (.msi) and ZIP (NSIS not supported by cargo-dist)
- **macOS**: ZIP (simplest), DMG (traditional, requires extra tooling), Homebrew
- **Linux**: Tarball and AppImage (AppImage not supported - requires third-party tool)

## Current Status: PARTIALLY COMPLETE 🔄

cargo-dist is configured and release automation is in place. Native installers build on tag push but MSI requires proper WiX template generation.

## Known Issues

- **MSI Installer**: Requires `wix/main.wxs` template generated by `cargo dist init`. This command doesn't work correctly in CI, causing build failures. The MSI feature is temporarily disabled until the template issue is resolved.

## Strategy

Using **cargo-dist** v0.30+ for cross-platform release automation.

## Native Installers - Technical Details

### Current State
cargo-dist currently produces:
- **Windows**: `.zip` archives
- **macOS**: `.tar.xz` archives
- **Linux**: `.tar.xz` archives

All releases include checksums (SHA256).

### Windows MSI
- **Status**: Configured but temporarily disabled due to WiX template issues
- MSI is the only Windows bundling installer available in cargo-dist
- NSIS is **not supported** by cargo-dist
- Requires WiX template at `wix/main.wxs` generated by `cargo dist init`
- The `dist init` command doesn't work correctly in CI environments

### Steps to Re-enable MSI
1. Run `cargo dist init` locally (requires cargo-dist installed)
2. This will generate proper `wix/main.wxs` template
3. Add generated files to version control
4. Re-enable `installers = ["msi"]` in dist-workspace.toml
5. Test in CI before merging

### macOS Installers

**Option 1: ZIP (Simplest - Recommended First Step)**
- Change `unix-archive` in Cargo.toml to `.zip`
- Already produces `.tar.xz` - switching to ZIP is trivial

**Option 2: DMG (Traditional macOS)**
- Requires additional tooling: GitHub Action like `L-Super/create-dmg-actions`
- Requires packaging binary as `.app` bundle

**Option 3: Homebrew Tap**
- cargo-dist supports this natively with `tap` config

### Linux AppImage
- **Not supported** by cargo-dist
- Would require manual build script or third-party tool
